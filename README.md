# order-check-vba

사람이 만든 제조의뢰서(xlsx)를 VBA로 생성한 기준 파일(xlsm)과 비교해 오류를 찾아 표시하는 검증 매크로입니다.

## 구성
| 파일 | 매크로 | 설명 |
|---|---|---|
| `src/HospitalCheck.bas` | `CheckHospital` | 병원(해외) 구간 검증: 바이알·패키지 묶음, 요일/규격, mCi 표기 |
| `src/DomesticCheck.bas` | `CheckDomestic` | 국내 구간 검증: 번호 연속성, 병원명/요일/규격/대리점 비교 |

## 사용법
1. 검증용 xlsm을 만들고 `Alt+F11` → 파일 → 가져오기로 `src/*.bas`를 추가
2. `Alt+F8` → `CheckHospital` 또는 `CheckDomestic` 실행
3. 파일 선택 창에서 ① 기준 xlsm ② 비교할 xlsx를 차례로 선택
4. 결과는 검증용 파일의 `검증결과` / `국내검증결과` 시트에 생성되고, 비교 대상 파일은 `원본이름_…표시` 로 복사본에 색칠되어 저장됩니다 (원본은 수정하지 않음)

## 주의
- 결과 시트 `사용방법`, `검증결과`, `국내검증결과`는 매크로가 사용하는 시트 이름입니다.
